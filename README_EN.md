# Maomao for Hermes Agent

**The plugins in this repository only support Hermes Agent.** They rely on its plugin hooks, gateway and tool APIs and are not drop-in plugins for other agent frameworks.

See the [Chinese README](README.md) for installation, model and credential configuration, supported embedding restrictions, privacy prerequisites, QQ connector isolation and testing. The public persona lives in [persona.md](plugins/maomao-companion/persona.md). This repository does not include deployed credentials, conversation histories, runtime data or recipient identifiers.
